1. This repo contains codes related to 2H-Ge nanowire analysis related to g-factor anisotropy and Rashba splitting.
2. Folder description:
   TB_Hamiltonian
         |---- Hamiltonian_mathematica_v2.py : real space Hamiltonian generated from mathematica
         |---- Hamiltonian_real_april.py : real space Hamiltonian generated directly in python
         |---- main_subband_parallelised.py : calculates subbands of the nanowire
         |---- Discretised_Hamiltonian.wls : generate Hamiltonian that can be used in python
