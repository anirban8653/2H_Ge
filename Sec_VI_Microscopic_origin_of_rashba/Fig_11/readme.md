# Figure 11 — Schematic energy-level diagram

This directory contains a schematic energy-level diagram based on the dominant-band contribution data presented in [Figure 10](../Fig_10/).

The levels illustrate the energy-level structure schematically; their positions and spacings are not drawn to scale and should not be interpreted as quantitative energy values.

- `level_2x1_combined.ipynb`: Notebook for generating the schematic.
- `level_diagram.pdf`: The resulting schematic energy-level diagram.
